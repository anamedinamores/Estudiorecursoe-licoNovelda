# Estudio del Recurso Eólico y Evaluación Energética en Novelda (Alicante)

Este repositorio contiene el código completo desarrollado en R para el procesamiento, análisis estadístico y estimación de producción eléctrica de un aerogenerador en la ubicación de Novelda (Alicante), utilizando datos meteorológicos horarios de la serie NASA POWER (2021–2025).

## Contenido del repositorio:
- `FENovelda.R`: Código fuente estructurado en R con la limpieza de datos, momentos estadísticos, rosa de los vientos, perfil logarítmico, ajuste de Weibull y cálculo de Energía Anual Producida.
- `POWER_Point_Hourly_20210101_20251231_038d39N_000d76W_UTC.csv`: Serie temporal de datos meteorológicos de entrada.
